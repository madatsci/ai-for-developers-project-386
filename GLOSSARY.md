# Календарь звонков

Сервис помогает посетителю выбрать удобное время для звонка с организатором без
долгого согласования в переписке.

## Language

**Звонок**:
Запланированный разговор посетителя с организатором.
_Avoid_: Встреча

**Бронирование**:
Процесс выбора времени и закрепления звонка за посетителем.
_Avoid_: Запись

**Тип звонка**:
Предлагаемый посетителю вариант звонка с собственными названием, описанием и
длительностью.
_Avoid_: Тип встречи, тип события, вид брони

**Отключённый тип звонка**:
Тип звонка, недоступный для новых бронирований, но сохраняемый для истории
уже созданных звонков.
_Avoid_: Удалённый тип звонка

**Режим работы**:
Общие границы времени, в которые организатор в принципе проводит звонки.
Действует для всех расписаний и типов звонков.

**Расписание**:
Именованный набор доступности, назначаемый одному или нескольким типам звонков.
_Avoid_: Календарь

**Доступность**:
Повторяющиеся недельные интервалы расписания, в которые организатор предлагает
бронирование звонков.

**Свободный слот**:
Полуоткрытый интервал времени для выбранного типа звонка, в который посетитель
может создать бронирование. Его длительность равна длительности типа звонка.

**Записаться**:
Начать бронирование звонка.

**Посетитель**:
Человек без аккаунта, который выбирает время и бронирует звонок.
_Avoid_: Гость

**Комментарий посетителя**:
Необязательный текст, который посетитель оставляет организатору при бронировании,
чтобы сообщить контекст или пожелания к звонку.
_Avoid_: Additional notes, заметка

**Организатор**:
Человек, который владеет календарём и предлагает доступное время для звонка.
_Avoid_: Владелец календаря
