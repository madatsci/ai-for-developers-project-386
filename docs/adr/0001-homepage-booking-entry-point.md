# Главная страница ведёт к бронированию звонка

Главная страница становится публичным лендингом для посетителя: она объясняет,
что сервис помогает выбрать удобное время для звонка без долгого согласования,
и ведёт к единственному целевому действию — бронированию звонка.

## Решение

- Сохранить название продукта «Календарь звонков» и использовать термины из
  `GLOSSARY.md`.
- Построить главную из компактной шапки, hero-блока, декоративного примера
  свободного времени, трёх шагов, финального призыва к действию и подвала.
- Все ссылки «Записаться на звонок» направить на `/booking`.
- Добавить `/booking` как честную страницу назначения с сообщением, что выбор
  времени появится позже, и ссылкой назад на главную.
- Реализовать светлый адаптивный интерфейс с синим акцентом, без декоративных
  анимаций, внешних изображений и ложных заявлений о несуществующих возможностях.

## Последствия

Настоящий выбор времени, создание бронирования, API и хранение данных остаются за
пределами решения. Декоративный календарь не является интерактивным и скрыт от
скринридеров; переходы между страницами доступны с клавиатуры и проверяются
роутерным тестом.
